# ColorPalette
My Computer Science Internal Assessment for the IB Diploma (High School)
This app is meant a Python-based tool that identifies and names colors from images (when you select a pixel). It extracts the RGB or HEX values of colors and maps them to the closest named color using web standards (CSS and HTML color specifications).
